# RuneTick

Grand Exchange prices, open offers, and cash in the RuneLite sidebar.

Features that talk to [Runetick](https://runetick.ironhopeshop.com) are off until you turn them on. Those settings warn that they send your IP address to a server RuneLite does not operate.

- Wide after-tax gaps and dips
- Live GE slots, with the current price and a hold / raise / lower / back-out call
- Optional upload of your own GE history, offers, and net worth
